# 🔍 Product Search with Elasticsearch (Spring Boot)

This project demonstrates how to build a **robust and flexible search system** using **Elasticsearch** integrated with **Spring Boot** and the **Elasticsearch Java Client**.

It focuses on real-world search requirements such as **partial text search**, **case-insensitive matching**, and **optional filtering** without overcomplicating the query logic.

---

## 🚀 Features

- 🔎 Partial product name search (e.g. `Lap` → `Laptop`)
- 🔡 Case-insensitive searching
- 💰 Optional price range filtering (`minPrice`, `maxPrice`)
- 🧠 Dynamic Elasticsearch `bool` query construction
- 🌐 REST API endpoint for searching products
- 🔄 Clean mapping between domain entities and Elasticsearch documents

---

## 🛠 Tech Stack

- Java 17  
- Spring Boot  
- Elasticsearch  
- Elasticsearch Java Client (8.x)  
- Gradle
